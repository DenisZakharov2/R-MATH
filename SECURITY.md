# Политика безопасности и приватности данных (Security Policy)

## Приватность данных учеников

Тренажёр **R MATH** разработан с соблюдением принципа **Privacy by Design** для детской образовательной среды:
1. **100% локальное хранение:** все данные анкеты (имя, фамилия, номер школы, класс), прогресс, игровая валюта и архив ответов хранятся исключительно локально в браузере пользователя (`localStorage` по ключу `roblox_math_trainer_save_v8`).
2. **Отсутствие сетевых запросов с персональными данными:** приложение не отправляет никаких данных на внешние серверы, не использует куки сторонних рекламных сетей и не содержит аналитических трекеров.
3. **Защита от XSS-инъекций:** все пользовательские строки (имя, фамилия, школа, класс) перед вставкой в SVG или HTML-карточки архива проходят обязательное экранирование спецсимволов через функцию `escapeHTML()`.

## Поддерживаемые версии

| Версия | Поддержка обновлений безопасности |
| :--- | :--- |
| `1.1.x` | ✅ Поддерживается |
| `1.0.x` | ❌ Обновитесь до `1.1.0` |

## Сообщение об уязвимости

Если вы обнаружили ошибку безопасности или проблему вёрстки/логики, создайте тикет в разделе **Issues** с шаблоном `Bug Report` или свяжитесь с владельцем репозитория напрямую.
