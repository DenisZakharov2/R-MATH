# Руководство по участию в разработке (Contributing Guide)

Спасибо за интерес к развитию образовательного проекта **R MATH: Тренажёр 4 класс**! Приложение создано так, чтобы учителя, методисты, родители и разработчики могли легко добавлять новые математические задания и игровые предметы без необходимости настраивать сборщики или серверное окружение.

## 🛠️ Как устроен проект

Весь код приложения находится в одном самодостаточном файле `index.html`. Это сделано намеренно:
* файл открывается двойным кликом на любом школьном компьютере или интерактивной доске даже без доступа в интернет;
* приложение легко размещается на **GitHub Pages** или любом статическом хостинге.

## ➕ Как добавить новые математические задания

### 1. Блок 1 — Сложение и вычитание в столбик
Найдите в `<script>` массивы `BLOCK1_ADD_2D`, `BLOCK1_ADD_3D`, `BLOCK1_ADD_4D`, `BLOCK1_SUB_2D`, `BLOCK1_SUB_3D`, `BLOCK1_SUB_4D` и добавьте новый объект `{ a, b }`:

```javascript
// Сумма (a + b) должна иметь ту же разрядность (2, 3 или 4 знака) и содержать хотя бы один перенос через десяток:
{ a: 48, b: 37 }

// Для вычитания: a > b, и хотя бы в одном разряде должен требоваться заём десятка:
{ a: 84, b: 29 }
```

### 2. Блок 2 — Порядок выполнения действий
Добавьте новый шаблон в массив `ORDER_TEMPLATES`:
* `tokens` — массив строк (числа, скобки `(`, `)` и знаки `+`, `−`, `×`, `÷`).
* `ops` — массив операций с указанием `tokenIdx` (индекс знака операции в массиве `tokens`), `order` (порядковый номер выполнения `1`, `2`, `3`), `label` (текст промежуточного действия) и `ans` (результат действия).

```javascript
{
  tokens: ['(', '50', '−', '23', ')', '÷', '3', '+', '18'],
  ops: [
    { tokenIdx: 2, order: 1, label: '50 − 23', ans: 27 },
    { tokenIdx: 5, order: 2, label: '27 ÷ 3', ans: 9 },
    { tokenIdx: 7, order: 3, label: '9 + 18', ans: 27 }
  ]
}
```

### 3. Блок 3 — Умножение в столбик и деление уголком
* Для умножения добавьте `{ a, b }` в `MULTIPLICATION_PROBLEMS` (`a` — двузначное или трёхзначное число, `b` — однозначный множитель `2..9`).
* Для деления уголком добавьте `{ dividend, divisor }` в `DIVISION_PROBLEMS`. Важно: `dividend` должен делиться на `divisor` без остатка, а первая цифра `dividend` должна быть больше или равна `divisor` (чтобы количество цифр частного совпадало с разрядностью делимого).

### 4. Блок 5 — Текстовые задачи
В функции `generateWordProblemData()` найдите объект `poolsByType` (`1` — сложение `+`, `2` — вычитание `−`, `3` — умножение `×`, `4` — деление `÷`) и добавьте новую задачу:

```javascript
{
  id: 'wp_add_5',
  op: '+',
  a: 64,
  b: 29,
  ans: 93,
  text: `В школьном саду ученики ${gradeGenitive} ${schoolGenitive} посадили 64 яблони и 29 груш. Сколько всего деревьев посадили ребята?`,
  unit: 'деревьев'
}
```

## 🎨 Как добавить новый скин в магазин

1. Добавьте описание предмета в массив `SHOP_ITEMS`, указав уникальный `id`, категорию (`hair`, `top`, `hat`, `glasses`, `pet` или `back`), название `name`, цену `price` в R$ и эмодзи `icon`.
2. В функции `buildHeroSVG(uid)` добавьте ветку `else if (eq.<category> === '<ваш_id>')` с SVG-разметкой в координатной сетке `viewBox="0 0 120 130"`.

## ✅ Требования к коду и проверка перед отправкой Pull Request

1. Используйте `kebab-case` для всех CSS-классов и HTML `id`.
2. Соблюдайте правила русской орфографии и обязательно используйте букву **«ё»** во всех текстах интерфейса (приложение предназначено для учеников 4 класса начальной школы).
3. Убедитесь, что для каждой созданной в рабочей области (`#workspace`) клетки `.cell-input` в массив `state.steps` добавляется соответствующий объект шага `{ el, expected, shortLabel, stepMsg }`.
4. Протестируйте прохождение нового задания в браузере и убедитесь, что оно корректно отображается в **Архиве заданий** (`📋`).
