**R MATH** — интерактивное одностраничное веб-приложение (SPA) для учеников 4 класса. Тренажёр помогает отрабатывать письменные вычисления в столбик и деление уголком, порядок выполнения действий в выражениях со скобками, таблицу умножения и деления на скорость, а также решение текстовых задач с полной записью решения по разрядам.

Приложение не требует серверной части, установки пакетов или подключения сторонних библиотек — весь код, векторная графика (SVG) и звуковой синтезатор (Web Audio API) упакованы в один автономный HTML-файл.

## ✨ Основные возможности

### 📚 5 учебных блоков (более 130 уникальных заданий)
| Блок | Тема | Кол-во заданий в раунде | Особенности механики |
| :--- | :--- | :--- | :--- |
| **Блок 1** | **Сложение и вычитание в столбик** | 5 примеров | Пошаговый ввод справа налево (от единиц к тысячам) для 2-, 3- и 4-значных чисел с обязательным заполнением ячеек **«в уме»** и **«заём»** (60 уникальных примеров в пуле). |
| **Блок 2** | **Порядок выполнения действий** | 5 примеров | Двухэтапное решение: сначала ученик расставляет номера действий `1`, `2`, `3` над знаками операций с учётом скобок и приоритета `×`/`÷`, а затем пошагово вычисляет каждое действие (12 шаблонов). |
| **Блок 3** | **Умножение в столбик и деление уголком** | 5 примеров | Чередование умножения двузначных/трёхзначных чисел на однозначное (с переносами в уме) и полного деления «уголком» с записью неполных делимых, остатков, сноса цифр и вычитаемых (24 примера). |
| **Блок 4** | **⚡ БЛИЦ: Таблица умножения и деления** | 10 заданий | Скоростной режим: на каждый пример даётся **8 секунд** с визуальным таймером. |
| **Блок 5** | **📖 Текстовые задачи с решением** | 5 задач | Трёхэтапный разбор задачи: 1) выбор знака действия (`+`, `−`, `×`, `÷`), 2) самостоятельная запись чисел задачи в столбик или уголком и поразрядное вычисление (с поддержкой переместительного свойства сложения), 3) запись итогового ответа с единицами измерения. |

### 🏆 Игровая мотивация и экономика
* **Валюта R$ (Ро):** начисляется за каждый верный пошаговый ввод (`+4 R$`), за полное решение примера (`+12 R$` без ошибок или `+5 R$` после исправления) и за серию ответов без ошибок (комбо-бонус `+3 R$` от 3 побед подряд, `+6 R$` от 5 побед подряд).
* **Система жизней (2 сердечка ❤️❤️):** на весь этап даётся право на одну ошибку (`−10 R$`). При второй ошибке в рамках этапа раунд завершается поражением.
* **Платная подсказка (`💡 15 R$`):** один раз за этап ученик может активировать подсказку, которая автоматически выполняет текущий шаг и открывает текстовые пояснения на оставшиеся шаги задания.
* **Ежедневные миссии (`🎯 Миссии дня`):** 3 ежедневных задания с прогресс-барами и наградой по **+100 R$** за каждое:
  1. Решить 20 примеров без ошибок.
  2. Решить 10 текстовых задач в столбик (Блок 5).
  3. Пройти раунд «Блиц на скорость» (Блок 4).

### 📋 Журнал тренировок (Архив и работа над ошибками)
* Автоматическая запись каждого решённого или прерванного задания (до 120 последних записей).
* Фильтрация по всем заданиям, только заданиям с ошибками или по конкретному учебному блоку (Блок 1–5).
* Детальный протокол ошибок: фиксируется, какую именно цифру или знак ввёл ученик, какое значение ожидалось и в каком разряде произошла ошибка.

## 🚀 Быстрый старт и размещение на GitHub

### Вариант 1. Локальный запуск
Скачайте репозиторий и откройте файл `index.html` в любом современном браузере (Chrome, Safari, Edge, Firefox) на компьютере, планшете или смартфоне:

```bash
git clone https://github.com/<ваш-логин>/R%20MATH.git
cd "R MATH"
open index.html
```

### Вариант 2. Публикация на GitHub Pages
В репозитории уже настроен автоматический деплой через GitHub Actions (`.github/workflows/pages.yml`):
1. Загрузите файлы репозитория в свой проект на GitHub.
2. Перейдите в раздел **Settings → Pages** вашего репозитория.
3. В блоке **Build and deployment → Source** выберите **GitHub Actions**.
4. При каждом коммите в ветку `main` (или `master`) тренажёр будет автоматически публиковаться по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## 🛠️ Технологический стек
* **HTML5 / CSS3:** адаптивная сетка (`CSS Grid` и `Flexbox`), поддержка мобильных экранов (`100dvh`), неоновый стеклянный интерфейс (`backdrop-filter: blur`).
* **Vanilla JavaScript (ES6+):** детерминированный конечный автомат пошаговой проверки разрядов без сторонних фреймворков.
* **Inline SVG Engine:** динамическая генерация персонажа и аксессуаров без внешних картинок.
* **Web Audio API:** процедурный синтез звуков в браузере без MP3/WAV-файлов.
* **Web Storage API (`localStorage`):** автоматическое сохранение прогресса, профиля, купленных скинов, миссий дня и архива ошибок под ключом `roblox_math_trainer_save_v8`.
